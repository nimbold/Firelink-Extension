# Edge Add-ons screenshots

These are capture instructions, not store screenshots. Do not upload this file to Partner Center. Screenshots are optional in Partner Center, but real screenshots are recommended because they help reviewers and users understand the extension.

If screenshots are submitted, capture them from a real Microsoft Edge installation after loading or installing the submitted `firelink-chromium.zip`. Do not use mockups or generated UI images as evidence of runtime behavior.

Capture clear, uncluttered images at 1280×800 or 640×480, with no private URLs, pairing tokens, cookies, account names, or unrelated browser extensions visible. Recommended set:

1. English popup showing a secure Firelink connection and the **Fetch media** action.
2. Hebrew or Persian popup showing the right-to-left layout and localized controls.
3. A page context menu showing **Download with Firelink**, selected-link download, and **Fetch media with Firelink**.
4. Firelink's Add window after a media-page handoff, with no private URL or token visible.
5. Firelink's Add window after a magnet or torrent handoff, with the request awaiting user review.

This checkout does not contain the Edge runtime, so real Edge screenshots and the manual Edge behavior checklist remain unverified until they are captured by the maintainer.
